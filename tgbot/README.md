# FX analysis Telegram bot
1. In Telegram open @BotFather -> /newbot -> copy the token.
2. `pip install requests pandas`
3. `TRADE_BOT_TOKEN=<token> ALLOWED_CHAT_IDS=<your chat id> python bot.py` (ALLOWED_CHAT_IDS optional)
4. Message the bot, press a pair button.
Needs a machine that stays on and can reach query1.finance.yahoo.com and api.telegram.org.
