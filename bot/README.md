## Քայլ 1 — Ստեղծիր ցուցադրական բոտը (10 րոպե)

1. Telegram-ում գրիր **@BotFather**-ին → `/newbot` → անուն՝ օրինակ `Demo Barbershop` → username՝ օրինակ `demo_barber_yerevan_bot`։
2. BotFather-ը կտա **տոկեն** (`123456:ABC...`)։ Այն ոչ մեկին մի՛ ցույց տուր։
3. Տեղադրիր Python 3.10+ (https://python.org), հետո այս թղթապանակում գործարկիր.
   ```bash
   pip install -r requirements.txt
   cp config.example.json config.json
   ```
   (Windows-ում `cp`-ի փոխարեն՝ `copy`)
4. Գործարկիր բոտը.
   ```bash
   # Mac / Linux
   BOT_TOKEN=քո_տոկենը python bot.py
   # Windows
   set BOT_TOKEN=քո_տոկենը
   python bot.py
   ```
5. Telegram-ում բացիր քո բոտը → `/start`։ Գրիր `/myid`, պատճենիր թիվը և դիր `config.json`-ի `"admin_ids": [այստեղ]` դաշտում։ Վերագործարկիր բոտը։ Հիմա նոր գրանցումների մասին ծանուցումները կգան քեզ։

Վերջ։ Այս ցուցադրական բոտի հղումն (`t.me/demo_barber_yerevan_bot`) ուղարկում ես վարսավիրանոցներին, որ փորձեն։

## Քայլ 3 — Միացրու նոր հաճախորդին (15 րոպե)

1. @BotFather-ում ստեղծիր նոր բոտ նրա անունով (օր.՝ `varpet_barber_bot`)։
2. Պատճենիր `bot` թղթապանակը, օրինակ՝ `clients/varpet/`։
3. `config.json`-ում փոխիր անունը, հասցեն, հեռախոսը, աշխատանքային ժամերը և ծառայությունները։ Աշխատանքային ժամերում փակ օրը նշվում է `null`-ով։
4. Տիրոջը խնդրիր գրել բոտին `/myid` և նրա ID-ն դիր `admin_ids`-ում (քոնը կարող ես թողնել նույնպես)։
5. Գործարկիր նրա տոկենով։ Յուրաքանչյուր հաճախորդ ունի իր թղթապանակը, իր տոկենը և իր տվյալների բազան (`bookings.db`)։

## Քայլ 4 — Որ աշխատի 24/7

Բոտն աշխատում է այնքան ժամանակ, քանի դեռ միացված է համակարգիչը, որտեղ այն գործարկված է։ Ցուցադրման համար բավական է քո համակարգիչը։ Երբ հայտնվի առաջին վճարող հաճախորդը, վարձիր փոքր սերվեր (VPS, ~2 000 ֏/ամիս)։ Մեկ սերվերի վրա կարող են աշխատել տասնյակ բոտեր։

Սերվերի վրա ավտոմատ գործարկման օրինակ (Linux, `systemd`)՝ `/etc/systemd/system/varpet-bot.service`.
```ini
[Unit]
Description=Varpet barber bot
After=network-online.target

[Service]
WorkingDirectory=/home/bots/clients/varpet
Environment=BOT_TOKEN=ՏՈԿԵՆԸ
ExecStart=/usr/bin/python3 bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now varpet-bot
```
