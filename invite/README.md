## Ինչպես միացնել (10 րոպե)
1. `index.html`-ում փնտրիր `CONTACT` և փոխիր `37400000000`-ը քո համարով, `your_username`-ը՝ քո Telegram/Instagram-ով։
2. GitHub → Settings → Pages → branch → Save։ Կայքը կլինի `https://gugodavtyan555.github.io/gugodavtyan555/invite/` հասցեով։
   (Կամ Netlify/Cloudflare Pages + սեփական դոմեն, օրինակ `.am`, ~10 000 ֏/տարի)։

## Ինչպես կատարել պատվերը
1. Հաճախորդից վերցրու. անունները, ամսաթիվը, վայրերը, ծրագիրը, RSVP-ի համար WhatsApp համարը, լուսանկար/երգ (ըստ ցանկության)։ **50% կանխավճար։**
2. Բացիր `create.html`, լրացրու, սեղմիր «Պատճենել», ուղարկիր հղումը հաճախորդին։
3. Լուսանկարի/երգի համար՝ վերբեռնիր ֆայլը `invite/media/` պանակ և տեղադրիր դրա հղումը։
4. Երկար հղումը կարճացնելու համար օգտագործիր Bitly կամ քո դոմենի redirect-ը։
