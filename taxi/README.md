# Ճամփա — տաքսու հավելված (դեմո)

Մեկ ֆայլ՝ `index.html`։ Բացիր հեռախոսով, աշխատում է առանց սերվերի։

- Քարտեզ (OpenStreetMap), քո գտնվելու վայրը, հասցեի որոնում և ընտրություն քարտեզի վրա
- Երթուղի, հեռավորություն, ժամանակ, գին 5 տարիֆով (Էկոնոմ, Կոմֆորտ, Բիզնես, Մինիվեն, Առաքում)
- Վճարում՝ կանխիկ / քարտ / Idram
- Պատվեր → վարորդի փնտրում → մեքենան գալիս է → ուղևորություն → գնահատական
- Ուղևորությունների պատմություն, մութ թեմա

Գները փոխվում են `TARIFFS` ցանկում (ֆայլի սկզբում)։

**Կարևոր.** սա դեմո է՝ վարորդները սիմուլյացիա են։ Իսկական ծառայության համար պետք են սերվեր,
վարորդի հավելված, վճարային համակարգ (օր.՝ Idram/ArCa) և տաքսու լիցենզիա։
