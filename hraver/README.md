# 🤖 Hraver — ավտոմատ հրավերների բիզնես

**Կայքը՝ https://hraver.gugodavtyan555.workers.dev** (արդեն տեղադրված է Cloudflare-ում, անվճար, 24/7)

## Ինչպես է աշխատում (առանց քեզ)
1. Հաճախորդը բացում է կայքը → **«Ստեղծել հրավեր»** → լրացնում է անունները, ամսաթիվը, վայրերը, բեռնում է լուսանկարը, տեսնում նախադիտումը։
2. Գրում է հեռախոսը, ընտրում փաթեթը (9 900 / 19 900 ֏) → «Պատվիրել»։
3. Ստանում է **անձնական էջ**, որտեղ կան նախադիտումը (կարմիր «ՆԱԽԱԴԻՏՈՒՄ» գրությամբ) և քո վճարման տվյալները։ Վճարում է և սեղմում «Ես վճարել եմ»։
4. **Քեզ Telegram-ում գալիս է ծանուցում** → ստուգում ես բանկի հավելվածում → սեղմում ես **«✅ Վճարված է»**։ ← սա է քո միակ աշխատանքը
5. Հրավերն ակտիվանում է, հաճախորդի էջում հայտնվում են հղումը և «Ուղարկել WhatsApp-ով» կոճակը։ Քեզ մոտ էլ հայտնվում է կոճակ, որով մեկ սեղմումով WhatsApp-ով կուղարկես նրան հղումները։
6. Հյուրերը պատասխանում են հրավերում, իսկ հաճախորդն իր էջում տեսնում է ցուցակը և ընդհանուր թիվը։ Նա կարող է հրավերը խմբագրել ցանկացած պահի։

## Միացում (մեկ անգամ, 3 րոպե)
1. Telegram → **@BotFather** → `/newbot` → անուն, օրինակ՝ `Hraver Admin` → պատճենիր տոկենը։
2. Բացիր **https://hraver.gugodavtyan555.workers.dev/setup** → տեղադրիր տոկենը → «Դառնալ ադմին» → **Start**։
3. Բոտին գրիր քո վճարման տվյալները (դրանք կտեսնի հաճախորդը)՝
   `/pay Քարտ՝ 4318 0000 0000 0000 (Անուն Ազգանուն)` և նոր տողում `Idram ID՝ 123456789`
4. `invite/index.html`-ում փոխիր `CONTACT` բաժինը (WhatsApp, Telegram, Instagram) և խնդրիր Claude-ին նորից տեղադրել։

## Բոտի հրամանները
- `/orders` — չվճարված պատվերները՝ կոճակներով
- `/stats` — այս ամսվա և ընդհանուր եկամուտը
- `/pay ՏԵՔՍՏ` — վճարման տվյալները
