# Ռազմավարությունների ստուգիչ (backtester)

Ծրագիրը ստուգում է 7 տարածված ռազմավարություն պատմական գների վրա և ցույց է տալիս
իրական հաղթանակի տոկոսը։ Իրական փող չի օգտագործում և Pocket Option-ին չի միանում։

## Ինչպես գործարկել ձեր համակարգչում

1. Տեղադրեք Python (python.org)
2. Տերմինալում (Windows-ում՝ cmd) գրեք.
   ```
   pip install pandas numpy yfinance
   python backtest.py
   ```

Այլ տարբերակներ.
- `python backtest.py --symbol GBPUSD=X`: այլ արժութային զույգ
- `python backtest.py --interval 5m`: 5 րոպեանոց մոմեր, վերջին 60 օրը
- `python backtest.py --payout 0.92`: եթե Pocket Option-ը 92% է վճարում
- `python backtest.py --synthetic`: պատահական գներ, առանց ինտերնետի

## Ինչպես կարդալ արդյունքը

- **Break-even**. 85% վճարման դեպքում պետք է հաղթել 54.1%-ից ավելի, որ գոնե զրոյի դուրս գաք։
- Տվյալները բաժանվում են երկու կեսի։ Ռազմավարությունը իրականում աշխատում է միայն եթե
  **երկու կեսում էլ** break-even-ից բարձր է։ Մեկ կեսում լավ արդյունքը սովորաբար պատահականություն է։
- 30-ից քիչ գործարքով արդյունքին մի վստահեք. 20 գործարքից 13-ը շահելը (65%) լրիվ պատահաբար էլ է լինում։
