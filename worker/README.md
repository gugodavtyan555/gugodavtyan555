# 📱 Բոտը միացնել iPhone-ից (անվճար, 24/7)

Բոտը կաշխատի **Cloudflare**-ի ամպում։ Այն անվճար է, աշխատում է 24/7, անգամ երբ հեռախոսդ անջատված է։ Բոլոր քայլերն արվում են iPhone-ի Safari-ից։ Մոտ 20 րոպե է պահանջվում։

> 💡 Cloudflare-ի կայքը հեռախոսում ավելի հարմար է «համակարգչային» տեսքով. Safari-ում հասցեի տողի **«ᴀA»** կոճակ → **Request Desktop Website**։

Քեզ պետք է BotFather-ի տոկենը (`123456:ABC...`)։ Այն արդեն ունես։

---

### 1. Գրանցվիր Cloudflare-ում
Բացիր **dash.cloudflare.com/sign-up** → գրանցվիր email-ով (անվճար է) → հաստատիր email-ը։

### 2. Ստեղծիր տվյալների բազա
Ձախ ընտրացանկ → **Storage & Databases** → **D1 SQL Database** → **Create** → անունը՝ `barber-bot` → **Create**։

### 3. Ստեղծիր Worker
Ձախ ընտրացանկ → **Workers & Pages** (կամ **Compute**) → **Create** → **Start with Hello World** → անունը՝ `barber-bot` → **Deploy**։

### 4. Տեղադրիր բոտի կոդը
1. Այլ ներդիրում բացիր `worker/worker.js` ֆայլը GitHub-ում.
   `github.com/gugodavtyan555/gugodavtyan555/blob/claude/earn-one-dram-per-second-1narbb/worker/worker.js`
   Սեղմիր **Copy raw file** կոճակը (📋 պատկերակ)։
2. Վերադարձիր Cloudflare → քո worker-ը → **Edit code**։
3. Ջնջիր ամբողջ տեքստը և տեղադրիր (Paste) պատճենած կոդը։
4. Կոդի սկզբում `ՓՈԽԻՐ ԱՅՍՏԵՂ` բաժնում կարող ես փոխել անունը, հասցեն, հեռախոսը, ժամերը և գները։ Ցուցադրական բոտի համար կարող ես թողնել այնպես, ինչպես կա։
5. Սեղմիր **Deploy**։

### 5. Միացրու բազան
Worker → **Settings** → **Bindings** → **Add binding** → **D1 database** → Variable name՝ **`DB`** (մեծատառ) → ընտրիր `barber-bot` → **Add/Deploy**։

### 7. Միացրու հիշեցումները
Worker → **Settings** → **Trigger Events** (կամ **Triggers**) → **Add** → **Cron Triggers** → ընտրիր **Every minute** (կամ գրիր `* * * * *`) → **Add**։

### 8. Միացրու բոտը Telegram-ին
Worker-ի էջում կա հասցե՝ `barber-bot.ՔՈ-ԱՆՈՒՆԸ.workers.dev`։ Բացիր այն Safari-ում՝ վերջում ավելացնելով **`/setup`**.

`https://barber-bot.ՔՈ-ԱՆՈՒՆԸ.workers.dev/setup`

Տեղադրիր BotFather-ի տոկենը դաշտում → **Միացնել** → սեղմիր **«Դառնալ ադմին Telegram-ում»** → Telegram-ում սեղմիր **Start**։ Հիմա նոր գրանցումների ծանուցումները կգան քեզ, իսկ `/today` և `/tomorrow` հրամաններով կտեսնես գրանցումների ցանկը։

### 9. Ստուգիր
Telegram-ում բացիր բոտդ → **📅 Գրանցվել** → գրանցվիր քեզ մոտ։ 🎉

## Նոր հաճախորդի (վարսավիրանոցի) միացումը

1. @BotFather-ում ստեղծիր նոր բոտ նրա անունով։
2. Կրկնիր 2–8 քայլերը նոր անուններով (օր.՝ բազան և worker-ը՝ `varpet-bot`)։ `CONFIG`-ում գրիր նրա տվյալները։
3. `/setup`-ից հետո բոտին գրիր `/addadmin` և ստացված հղումն ուղարկիր վարսավիրանոցի տիրոջը։ Նա էլ կստանա ծանուցումները։

Անվճար տարբերակը բավական է տասնյակ վարսավիրանոցների համար։

## Եթե ինչ-որ բան չի աշխատում

- **Բոտը չի պատասխանում.** նորից բացիր `/setup` հասցեն։
- **«DB binding-ը չկա».** 5-րդ քայլում անունը պետք է լինի ճիշտ `DB`, մեծատառերով։
- **«Տոկենը սխալ է».** ստուգիր, որ տոկենը պատճենված է ամբողջությամբ, առանց բացատների։
- **Հիշեցումներ չեն գալիս.** ստուգիր 7-րդ քայլը։
