# Հարցաշար հաճախորդին (պատճենիր և ուղարկիր)

**HY**
Բարև Ձեզ։ Ներկայացումը պատրաստելու համար խնդրում եմ պատասխանել.
1. Թեման (ինչի մասին է)
2. Ում համար է (դասարան/դասախոս/ընկերություն) և ինչ նպատակով
3. Քանի սլայդ
4. Լեզուն (հայերեն / ռուսերեն / անգլերեն)
5. Գույն կամ ոճ (խիստ / վառ / մուգ), եթե կա նախընտրություն
6. Եթե ունեք՝ ուղարկեք նյութեր, լուսանկարներ, լոգո
7. Երբ է պետք (ժամ/օր)

**RU**
Здравствуйте! Для подготовки презентации ответьте, пожалуйста:
1. Тема
2. Для кого и с какой целью (класс/преподаватель/компания)
3. Сколько слайдов
4. Язык (армянский / русский / английский)
5. Цвет или стиль (строгий / яркий / тёмный), если есть пожелания
6. Материалы, фото, логотип — если есть
7. К какому сроку нужно
