# Ներկայացումների ծառայություն (PowerPoint)

## Ֆայլեր
- `nimush-student.pptx`. ուսանողական նմուշ (7 սլայդ, պատմություն)
- `nimush-biznes.pptx`. բիզնես նմուշ (6 սլայդ, գրաֆիկով)
- `build.js`. ստեղծող սկրիպտ (pptxgenjs)
- `listing.md`. List.am-ի հայտարարություն
- `questionnaire.md`. հաճախորդին ուղարկվող հարցաշար

## Պատվերի գործընթաց
1. Հաճախորդը գրում է List.am-ով։ Դու նրան ուղարկում ես `questionnaire.md`-ի տեքստը։
2. Նրա պատասխանները ուղարկում ես Claude-ին՝ «Կարդա presentations/README.md, նոր պատվեր՝ …»։
3. Claude-ը պատրաստում է `.pptx` (build.js-ի հիման վրա), դու ուղարկում ես հաճախորդին։
4. 50% կանխավճար, մնացածը՝ ֆայլն ուղարկելուց առաջ (նախ ուղարկիր 2 սլայդի նախադիտում)։
